# Backup Beaver

*A pet app by Astra.*

**Status:** placeholder. Not built yet.

Backup Beaver is a planned pet app for Astra's Pet Apps (the Cage). Its job and features are still to be decided.

## Planned

- Pet registry entry in `pets.json` of [astras-pet-apps](https://github.com/findastra/astras-pet-apps)
- Web stand-in in `apps/` once there is something to show
- Standard moods: idle, blink, happy, curious, worried, sad, sick, alarmed, sleep

## Not yet created

- Registry entry and art

## How to run it

Open `index.html` in any modern browser. It shows a placeholder page and nothing else.
